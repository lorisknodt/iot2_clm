Les drawables regroupent les ressources graphiques de ton application. Ils incluent tous les fichiers d’images et de vecteurs utilisés dans l’UI.

- **Fonction principale :**  
  *Fournir les éléments visuels* (icônes, backgrounds, formes personnalisées, etc.) pour ton interface.

- **Types courants de drawables :**
  - **Bitmap** : Images (PNG, JPG, etc.).
  - **Vector** : Fichiers XML qui décrivent des formes vectorielles (généralement plus évolutifs et légers pour des icônes).
  - **Shape Drawable** : Décrit des formes simples et des fonds personnalisés en XML.
  - **StateListDrawable** : Permet de gérer différents états (normal, appuyé, sélectionné) pour une même vue.

- **Utilisation :**
  - Dans les layouts pour définir des icônes ou des images de fond.
  - Dans les adaptateurs pour afficher des images dans une liste.
  - Dans les fichiers de styles pour uniformiser l'apparence de l'application.
